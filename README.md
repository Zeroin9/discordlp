# Discord Points Bot

Discord-бот для управления системой очков/рейтинга пользователей на сервере Discord.
Бот автоматически начисляет баллы лояльности (LP) участникам голосовых каналов, позволяет
тратить их на платные действия и устраивать пари в стиле Twitch Predictions.

## Технологии

- **Язык**: Java 21
- **Фреймворк**: Spring Boot 4.1.0 (WebMVC, Data JPA, Thymeleaf)
- **Discord API**: JDA 6.4.2
- **База данных**: PostgreSQL
- **Миграции БД**: Flyway
- **Сборка**: Gradle
- **Тесты**: JUnit 5, Mockito, AssertJ, Testcontainers, JaCoCo

## Функциональность

### Автоматическое начисление баллов

Каждые 5 минут участникам голосовых каналов начисляются баллы:

| Состояние | Начисление |
|---|---|
| Заглушен или в мьюте | 0 LP |
| Обычный участник | 100 LP |
| Зритель (в канале со стримером) | 150 LP |
| Стример (при наличии зрителей) | 200 LP |

AFK-канал исключается. Подробности — [docs/commands.md](docs/commands.md).

### Команды

| Команда | Права | Описание |
|---|---|---|
| `/lp` | все | Просмотр своего баланса |
| `/lpkick <user>` | все | Отключить участника от голосового канала за 10 000 LP |
| `/lpmute <user>` | все | Замьютить участника за 50 000 LP |
| `/lp-pari <title>` | все | Создать пари, на исход которого участники ставят LP |
| `/lpuser <user>` | ADMINISTRATOR | Просмотр баланса участника |
| `/lpadd <user> <amount>` | ADMINISTRATOR | Начисление баллов участнику |
| `/lpremove <user> <amount>` | ADMINISTRATOR | Списание баллов у участника |

### Пари (Twitch Predictions)

`/lp-pari <название>` публикует сообщение-опрос с кнопками «Да» и «Нет». Участники нажимают
кнопку, вводят сумму ставки в модальном окне, и она сразу списывается с баланса. Автор пари
ставки делать не может, а участник не может изменить выбор или поставить на оба исхода.
Управление доступно только автору: «Остановить ставки», «Завершить: ДА», «Завершить: НЕТ»,
«Отменить».

Выплаты считаются по схеме тотализатора: ставки складываются в общий пул, из него удерживается
комиссия организатора, а призовой фонд делится между победителями пропорционально ставкам.

```
призовой фонд      = общий пул − комиссия
коэффициент        = призовой фонд / пул варианта
выплата победителю = ставка × коэффициент
```

- **Выигрыш**: доля призового фонда по итоговому коэффициенту
- **Проигрыш**: ставка сгорает и уходит в призовой фонд
- **Никто не угадал**: 100% возврат всем участникам, комиссия не удерживается
- **Отмена**: 100% возврат всем участникам
- **Тайм-аут**: пари, висящее дольше `PARI_TIMEOUT_HOURS` (по умолчанию 24 ч), отменяется
  автоматически с возвратом ставок

Коэффициенты живые: пока пари открыто, они пересчитываются с каждой новой ставкой, а итоговым
становится тот, что зафиксирован при объявлении исхода. В отличие от фиксированного множителя,
тотализатор не создает валюту из воздуха — сумма выплат всегда равна пулу за вычетом комиссии.

Прием ставки выполняется в одной транзакции под `SELECT ... FOR UPDATE` на строке баланса,
поэтому спам-клики не приводят к двойным тратам и уходу баланса в минус. Начисление
выигрышей идемпотентно: итоги розыгрыша фиксируются один раз, каждая ставка рассчитывается
в собственной транзакции и помечается флагом `settled`, а незавершенный расчет (например,
после рестарта сервиса) доводит до конца планировщик.

Полное описание — [docs/pari.md](docs/pari.md).

### Веб-дашборд

`GET /dashboard` — таблица участников с балансами, временем в голосовых каналах,
пагинацией и сортировкой.

Колонка «Время в конфе» не хранится в БД: баллы начисляются фиксированными порциями раз
в 5 минут, поэтому время восстанавливается из журнала начислений как
`Σ (баллы по причине / начисление за интервал) × 5 минут`. Учитываются только причины
`VOICE_STANDARD`, `VOICE_VIEWER` и `VOICE_STREAMER` — ручные начисления и выигрыши в пари
время не увеличивают. Подробности — [docs/commands.md](docs/commands.md).

## Установка и запуск

### Требования

- JDK 21
- PostgreSQL
- Docker — только для интеграционных тестов

### Конфигурация

Создайте файл `.env` на основе `.env.example`:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_BOT_TOKEN` | — | Токен бота Discord |
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://localhost:5432/discordlp` | Адрес БД |
| `SPRING_DATASOURCE_USERNAME` | `postgres` | Пользователь БД |
| `SPRING_DATASOURCE_PASSWORD` | `postgres` | Пароль БД |
| `PARI_TIMEOUT_HOURS` | `24` | Через сколько часов открытое пари отменяется автоматически; `0` — без тайм-аута |
| `PARI_COMMISSION_RATE` | `0.05` | Доля общего пула, удерживаемая как комиссия организатора; `0` — без комиссии |

### Сборка и запуск

```bash
# Проверка компиляции
.\gradlew.bat compileJava

# Тесты (+ отчет о покрытии в build/reports/jacoco/test/html/index.html)
.\gradlew.bat test

# Сборка проекта
.\gradlew.bat build

# Запуск приложения
.\gradlew.bat bootRun

# Запуск вместе с БД в Docker
docker compose up -d
```
