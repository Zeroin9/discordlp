# Discord Points Bot

Discord-бот для управления системой очков/рейтинга пользователей на сервере Discord. Бот автоматически начисляет баллы лояльности (LP) пользователям, находящимся в голосовых каналах.

## Технологии

- **Язык**: Java 21
- **Фреймворк**: Spring Boot 4.1.0 (WebMVC, Data JPA, Thymeleaf)
- **Discord API**: JDA 6.4.2
- **База данных**: PostgreSQL
- **Миграции БД**: Flyway
- **Сборка**: Gradle

## Функциональность

### Автоматическое начисление баллов
Бот автоматически начисляет баллы лояльности (LP) каждые 5 минут пользователям, находящимся в голосовых каналах:

- **Заглушенный участник**: 0 LP
- **Обычный участник**: 100 LP
- **Стример** (ведет активный стрим): 200 LP
- **Зритель** (в канале со стримером, но не стримит): 150 LP

### Команды
- `/lp` - просмотр вашего баланса
- `/lpkick` - отключить участника за 10 000 LP
- `/lpuser` - просмотр баланса участника (только для администраторов)
- `/lpadd` - начисление баллов участнику (только для администраторов)
- `/lpremove` - списание баллов у участника (только для администраторов)
- `/lp-pari <название>` - создать пари, на исход которого участники ставят поинты

### Пари (Twitch Predictions)
Команда `/lp-pari <название>` публикует сообщение-опрос с кнопками «Да» и «Нет». Участники нажимают кнопку,
вводят сумму ставки в модальном окне, и она сразу списывается с баланса. Автор пари ставки делать не может,
а участник не может изменить выбор или поставить на оба исхода.

Управление доступно только автору: «Остановить ставки», «Завершить: ДА», «Завершить: НЕТ», «Отменить».

- **Выигрыш**: ставка x2 (ставка возвращается плюс 100% сверху)
- **Проигрыш**: ставка сгорает
- **Отмена**: 100% возврат всем участникам
- **Тайм-аут**: пари, висящее дольше `PARI_TIMEOUT_HOURS` (по умолчанию 24 ч), отменяется автоматически с возвратом ставок

Прием ставки выполняется в одной транзакции под `SELECT ... FOR UPDATE` на строке баланса, поэтому спам-клики
не приводят к двойным тратам и уходу баланса в минус. Начисление выигрышей идемпотентно: каждая ставка
рассчитывается в собственной транзакции и помечается флагом `settled`, а незавершенный расчет (например,
после рестарта сервиса) доводит до конца планировщик.

Обратите внимание: жесткий множитель x2 не гарантирует нулевую сумму в рамках одного пари — если большинство
поставит на верный исход, суммарный баланс участников вырастет.

## Установка и запуск

### Требования
- JDK 21
- PostgreSQL

### Конфигурация
Создайте файл `.env` на основе `.env.example` и заполните необходимые параметры:
- `DISCORD_BOT_TOKEN` - токен бота Discord
- Параметры подключения к базе данных PostgreSQL
- `PARI_TIMEOUT_HOURS` - через сколько часов открытое пари отменяется автоматически (по умолчанию 24, `0` - без тайм-аута)

### Сборка и запуск

```bash
# Проверка компиляции
.\gradlew.bat compileJava

# Сборка проекта
.\gradlew.bat build

# Запуск приложения
.\gradlew.bat bootRun
```
